### Finding 1 — NBSP/Unicode whitespace parity (Important)
`wc_tokenize` split on `"[[:space:]]+"`, which is ASCII-only, so a token glued by NBSP U+00A0 stayed one token in R while Python's `str.split()` splits on all Unicode whitespace. Changed the `strsplit` pattern in `R/tokenizer.R` to `"(*UCP)\\s+"` (kept `perl = TRUE`) so PCRE `\s` matches Unicode whitespace, matching Python. Added one new test block to `tests/testthat/test-tokenizer.R`:
```r
test_that("NBSP is treated as splitting whitespace (Python parity)", {
  expect_setequal(wc_tokenize("perch\u00E9\u00A0citt\u00E0"), c("perch\u00e9", "citt\u00e0"))
  expect_setequal(wc_tokenize("a\u00A0b"), c("a", "b"))
})
```
